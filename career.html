Career Viewer

Open an IL-2 Korea career file

Career files are SQLite databases, one per pilot, stored in your installation's data\Career folder. Nothing is uploaded — the file is read entirely inside your browser.

This viewer never writes to your career file. Editing is a separate, later step — and the game must be closed before any tool writes to it.
