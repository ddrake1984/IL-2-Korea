# IL-2 Korea External Graphics Configurator

A self-contained, offline HTML tool for editing the `[KEY = graphics]` section of an IL-2 Korea `startup.cfg` file — laid out to visually match the in-game Graphics Settings menu, including the Extended & Hidden Settings section.

## Usage

1. Open `index.html` in any modern desktop browser (Chrome, Edge, Firefox). No installation, server, or internet connection required.
2. Load your `startup.cfg` file (usually found in your IL-2 Korea installation's `data` folder).
3. Adjust settings using the same layout and options as the in-game menu.
4. Save the file back out — only the graphics section is modified; every other section of your `startup.cfg` is preserved byte-for-byte.

## Notes

- Everything runs locally in your browser. Your `startup.cfg` is never uploaded anywhere.
- Works entirely offline once the page is loaded.
