IL-2 Korea Tools

A small collection of browser tools for IL-2 Sturmovik: Korea. Each one runs entirely on your own machine — pick a file, work on it, and nothing ever leaves the browser.

Graphics Configurator

graphics.html · startup.cfg
Edits your file

Edit the graphics section of your startup.cfg in a layout that mirrors the in-game Graphics Settings menu — including the extended and hidden settings the menu never shows you.

  • Laid out to match the in-game menu exactly
  • Saves straight back to the original file
  • Every other section preserved byte-for-byte
  • Single file, nothing else needed

Career File Viewer

career.html · data\Career\*.db
Read-only

Open a pilot career file and read it as a career record — squadron roster, kill board and victory log, mission briefings, and a decoded day-by-day timeline of the whole tour.

  • Roster, aircraft, supply and decorations
  • Victory log naming every enemy crew
  • Mission log with the original briefings
  • Never writes to your career file

Task Editor Missions

taskeditor.html · QuickMission\Presets\*.json
Edits your file

Open a mission you saved in the in-game Task Editor and set the things that screen hides or randomises — exact countries, callsigns, tail codes and per-formation AI skill — then load it back in the game as normal.

  • Callsigns filtered to the ones your country can use
  • Weather, time and season in the game's own terms
  • Loadout data passed through untouched
  • Missions are 2 KB — small enough to share

Cooperative Converter

coop.html · data\Missions\_gen.Mission
Writes new files

Turn a mission you built in the Task Editor into a cooperative one you can fly with friends — briefing text included, and any number of flights on either side made flyable.

  • Finds your flight automatically
  • Copies the briefing the game generated
  • Two-sided coop, not just one aircraft type
  • Touches five lines and leaves the rest alone

Running these offline

Everything here works without an internet connection once the page has loaded, and no file you open is ever uploaded anywhere. You can also download the files and open them straight from disk.

One wrinkle if you do: the Career File Viewer needs sql-wasm.wasm kept in the same folder as career.html, and browsers block a file:// page from loading its own engine — so on first run it asks you to point at that file once, then remembers it. The Graphics Configurator is a single self-contained file with no such step.
