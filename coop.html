Turn a generated mission into one you can fly with friends

Build a mission in the in-game Task Editor and fly it once. The game writes it to data\Missions\_gen.Mission. This converts that into a cooperative multiplayer mission — briefing text included, which is the part the older converter left behind.

Pick your data folder and everything is found and written automatically. Opening a single file instead works too, but the briefing can't come along.

The game keeps only the mission you flew most recently — it overwrites _gen.Mission every time. Whichever mission you want to convert, fly that one last.

Converting again overwrites .Mission and the language files, but anything left over from a previous run — a language you no longer have, or a .msnbin and .list made by the resaver — stays behind and keeps being used. Delete a mission's whole set before rebuilding it if you want a clean slate.
One manual step afterwards. This writes the mission and its text, which is what the game reads. It cannot produce the .msnbin or .list companion files — those use a hash that isn't any standard checksum. The game ships the tool that makes them: drop your new mission onto bin\resaver\MissionResaver.exe. The shipped Korea coop example has no .msnbin at all, so try it as-is first — you may not need this.
