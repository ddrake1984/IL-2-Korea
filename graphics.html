Why these exist: the in‑game menu only exposes a subset of what startup.cfg actually controls. Everything below is read directly from your file — including settings the developers consider internal (mostly VR headset tuning, multi‑GPU and memory options). They're all still ordinary numbers in a text file, but a few can produce a black screen or crash if set far outside their normal range, so change one thing at a time and keep a backup of your original file.
Works entirely in your browser — nothing is uploaded anywhere. Settings and presets exist only for this browser tab session; use Presets → Export to save them to a file you can re‑import next time. Field descriptions are compiled from the game's own settings menu, community documentation (IL‑2 Sturmovik forums) and the structure of the file itself; a few of the more obscure VR/internal fields are best‑effort interpretations — always keep a backup of your original startup.cfg before experimenting.
